# Product Guidelines

## Tone & Messaging
- **Professional & Functional:** The application maintains a direct and efficient communication style. Labels are concise, and messaging (if any) is purely informative. No conversational language or fluff is used, reinforcing its status as a system utility.

## Visual Identity
- **Windows 11 Native Integration:** The UI adheres strictly to Windows 11 aesthetics. This includes:
    - **Color Palette:** Utilizing standard system-defined dark theme colors and neutral near-black backgrounds.
    - **Typography:** Exclusively using **Segoe UI** at system-standard sizes (Title: 20–22px, Body: 13–14px, Labels: 12px).
    - **Minimalism:** No shadows, gradients, or non-native custom theming.

## Layout & Spacing
- **Grid-Based Consistency:** A strict spacing system of 8, 16, and 24 pixels is applied to all margins, padding, and element separation.
- **Structured Content:** A vertical stack layout with a fixed-width content column ensures the UI remains focused and professional, regardless of window size.

## Interaction Design
- **Real-Time Responsiveness:** Display brightness is updated immediately as sliders are manipulated, providing instant visual feedback.
- **Subtle Feedback Loops:** UI elements like sliders and interactive targets provide subtle hover feedback to signify interactivity without being distracting.
- **Precision Hit Targets:** Sliders and controls feature large hit targets for ease of use with both mouse and touch inputs.
